🚀 Ariel - Smart Crypto Insights App

📌 Overview

Ariel is a powerful app designed to provide users with real-time insights into Solana wallets, market trends, and trading activity. The app features multiple pages that deliver essential data, including profit & loss tracking, AI-powered wallet discovery, social sentiment monitoring, and volume tracking.

📂 Features

🔹 PnL Page

Displays real-time profit & loss (PnL) data for a connected Solana wallet.

Tracks realized and unrealized gains.

Supports multiple timeframes: 1D, 7D, 1M, and Total.

Access Requirement: Minimum 100,000 (100K) tokens in the wallet.

🔹 Findr AI Page

Uses the in-house AI agent, Ariel, to discover and track top-performing wallets.

Provides continuous updates with the best wallets to monitor.

Access Requirement: Minimum 500,000 (500K) tokens in the wallet.

🔹 X Monitor Page

Aggregates and updates the latest tweets from top influencers on X (formerly Twitter).

Tracks individuals known for being early to trends and discovering hidden gems.

Access Requirement: Minimum 350,000 (350K) tokens in the wallet.

🔹 Volume Watch Page

Displays high-volume tokens in real-time.

Helps users identify trending tokens and track market activity.

Access Requirement: Minimum 300,000 (300K) tokens in the wallet.

🔧 Tech Stack

Blockchain: Solana integration for wallet tracking.

AI: Custom AI agent Ariel for wallet discovery.

Social Data: X (Twitter) API for sentiment monitoring.
